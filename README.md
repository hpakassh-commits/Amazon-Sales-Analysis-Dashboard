# Amazon Sales Analysis Dashboard

## 📊 Project Overview

This project is an interactive Amazon Sales & Product Analytics Dashboard developed using Microsoft Power BI.

The dashboard helps analyze sales performance based on products, states, cities, order status, and units sold.

## 🎯 Objectives

- Analyze overall sales performance
- Identify top-performing states and cities
- Analyze product-wise sales
- Track total sales and units sold
- Analyze order status
- Create an interactive business dashboard

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Transformation
- Data Visualization

## 📌 Dashboard Pages

### 1. Overview

The Overview page provides a summary of Amazon sales performance.

It includes:

- Total Sales
- Total Units
- Seller Count
- Sales by State
- Sales by City
- Sales Trend
- Order Status Filter
- Product Filter

### 2. Products

The Products page displays products using an interactive product gallery.

It includes:

- Product Images
- Product Names
- Product Selection
- Interactive Navigation

### 3. Product View

The Product View page provides detailed information about the selected product.
